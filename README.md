# ระบบตลาดนัดส่งต่อสิ่งของและหนังสือเรียนมือสองภายในมหาวิทยาลัย

## 1. รายละเอียดโครงงาน

ระบบตลาดนัดส่งต่อสิ่งของและหนังสือเรียนมือสองภายในมหาวิทยาลัย
เป็นระบบสำหรับช่วยให้นักศึกษาและบุคลากรสามารถซื้อ ขาย หรือส่งต่อ
หนังสือเรียน อุปกรณ์การศึกษา เฟอร์นิเจอร์หอพัก และสิ่งของเครื่องใช้
ที่ไม่ได้ใช้งานแล้วแต่ยังอยู่ในสภาพดี

ระบบมีจุดประสงค์เพื่อช่วยลดค่าใช้จ่ายของนักศึกษา เพิ่มความสะดวกในการ
ค้นหาสินค้ามือสอง และช่วยให้สามารถนัดรับ-ส่งสินค้าภายในพื้นที่มหาวิทยาลัยได้

---

## 2. ปัญหาและความสำคัญ

ปัจจุบันการซื้อขายหรือส่งต่อสิ่งของมือสองภายในมหาวิทยาลัยมักใช้
กลุ่ม Social Media ทั่วไป เช่น Facebook Groups ซึ่งทำให้โพสต์ถูกดันหาย
อย่างรวดเร็ว และค้นหาสินค้าตามรายวิชาหรือหมวดหมู่ได้ยาก

นอกจากนี้ยังมีปัญหาเรื่องการยืนยันตัวตนของผู้ซื้อและผู้ขาย รวมถึงความเสี่ยง
ในการถูกหลอกลวง และยังไม่มีระบบนัดรับ-ส่งสินค้าภายในพื้นที่มหาวิทยาลัย
อย่างเป็นรูปธรรม

ระบบนี้จึงถูกพัฒนาขึ้นเพื่อช่วยลดภาระค่าใช้จ่ายของนักศึกษา
จัดหมวดหมู่สินค้าให้ค้นหาได้ง่าย และเพิ่มความสะดวกในการซื้อขาย
และส่งต่อสิ่งของภายในมหาวิทยาลัย

---

## 3. ผู้ใช้เป้าหมาย

### ผู้ซื้อ
นักศึกษาและบุคลากรที่ต้องการค้นหาหนังสือหรือสิ่งของมือสอง
สภาพดีในราคาประหยัด และสามารถรับของได้สะดวกภายในมหาวิทยาลัย

### ผู้ขาย
นักศึกษาและบุคลากรที่ต้องการส่งต่อสิ่งของที่ไม่ได้ใช้งานแล้ว
เพื่อขายหรือส่งต่อให้ผู้อื่น

### ผู้ดูแลระบบ (Admin)
เจ้าหน้าที่หรือผู้พัฒนาที่ทำหน้าที่ตรวจสอบความถูกต้องของการลงทะเบียน
และจัดการโพสต์ที่ไม่เหมาะสม

---

## 4. ฟังก์ชันหลักของระบบ

### Authentication
เข้าใช้งานด้วย E-mail มหาวิทยาลัย เพื่อยืนยันว่าเป็นบุคคลภายในมหาวิทยาลัย

### Catalog & Search
ค้นหาสินค้าแยกตามหมวดหมู่ เช่น หนังสือเรียนตามรหัสวิชา
อุปกรณ์หอพัก และอุปกรณ์ไอที

### Chat & Deal
ระบบแชทสำหรับติดต่อผู้ซื้อและผู้ขาย รวมถึงนัดหมายจุดรับ-ส่ง
สินค้าภายในมหาวิทยาลัย

### Trust & Rating
ระบบให้คะแนนความน่าเชื่อถือของผู้ซื้อและผู้ขาย

## 6. สมาชิกและหน้าที่

| สมาชิก | บทบาท | หน้าที่ |
|---|---|---|
| นางสาวโสรญา สวรรค์งาม | Project Manager / Product Owner | บริหารจัดการโครงการ รวบรวม Requirement ทำ Backlog และจัดลำดับความสำคัญของ User Stories |
| นางสาวเกสรา ชำนิเขตกิจ | UI/UX Designer & System Analyst | ออกแบบ Wireframe/Prototype ด้วย Figma และออกแบบ Database Schema & API Endpoints |
| นายวรชิต คำอินทา | Full-Stack Developer (Lead Dev) | พัฒนาระบบ Authentication การลงประกาศ ระบบค้นหา และระบบ Chat |
| นายปุรเชษฐ์ศิริเขตรกิจ | DevOps & QA Engineer | พัฒนาระบบ Rating/Review ทดสอบระบบ Deploy ระบบขึ้น Cloud Server และรวบรวม Feedback |

7. วัตถุประสงค์ของโครงงาน

- ช่วยให้นักศึกษาสามารถส่งต่อสิ่งของที่ไม่ได้ใช้งานแล้ว
- เพิ่มความสะดวกในการค้นหาสินค้าตามหมวดหมู่
- เพิ่มความปลอดภัยด้วยการยืนยันตัวตนด้วย E-mail มหาวิทยาลัย
- สนับสนุนการนัดรับ-ส่งสินค้าภายในพื้นที่มหาวิทยาลัย
- ลดการทิ้งสิ่งของที่ยังสามารถใช้งานได้
